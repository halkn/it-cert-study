# 問題品質ブラインド受験プロンプト

添付bundleに含まれる問題へ回答してください。次の条件を厳守します。

1. 全問題の回答を確定するまで、正解、解説、question registry、git diff、外部資料を参照しない。
2. 各問について、選択肢ID、確信度（high／medium／low）、迷った理由を記録する。
3. 全回答確定後にだけ採点用データを受け取り、総合・Domain別に採点する。
4. 複数解釈、不自然に弱いdistractor、正解位置からの推測可能性を報告する。
5. 知識がなくても消去できる問題は、正答しても品質上の問題として記録する。

合格基準は総合80%以上、各Domain70%以上です。ファイルは編集しません。
