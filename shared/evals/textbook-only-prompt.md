# textbook単独Coverage監査プロンプト

添付bundle内のtextbookだけを根拠に、模擬問題へ回答してください。モデルの一般知識で補わず、次の条件を厳守します。

1. 利用できる根拠はbundle内のtextbook本文だけとする。
2. 全問題の回答を確定するまで、正解、解説、question registry、git diff、公式Webを参照しない。
3. 各問について、選択肢ID、textbookファイル、見出し、正解を支える説明を記録する。
4. 誤答をtextbook本文から除外できるか記録する。
5. 根拠がなければ、知識上回答できても`missing`とする。
6. 正解の一部だけを説明できる場合、または誤答除外に本文外の知識が必要なら`partial`とする。
7. 正解と誤答除外を本文で説明できる場合だけ`sufficient`とする。
8. 全回答と根拠を確定した後にだけ採点用データを受け取る。

合格基準は総合80%以上、各Domain70%以上、`sufficient`が90%以上、曖昧な問題0件です。ファイルは編集しません。
