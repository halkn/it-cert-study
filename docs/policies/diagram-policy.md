# Diagram Policy

図は装飾ではなく、1 枚につき 1 つの学習目的を持つ教材です。

## 図にする対象

階層、権限関係、データフロー、状態遷移、複数方式の選定、性能ボトルネックなど、文章だけでは関係を誤解しやすい内容を優先します。単純な用語列挙は無理に図にしません。

## 形式

- Mermaid: フロー、シーケンス、簡単な階層。差分レビューしやすい場合。
- SVG: 複雑なアーキテクチャ、配置、概念図。アクセシビリティ用の title/description を含める。
- その他: 保守性と再生成手順を `diagrams.json` に記録できる場合だけ使用する。

## 必須メタデータ

`docs/diagrams.json` に ID、学習目的、対応 objective、根拠の source ID、形式、ファイル、状態、最終確認日を登録します。公式図の単純転載は禁止です。

## レビュー観点

- 本文と用語・方向・境界が一致する。
- 根拠となる公式資料と一致する。
- 色だけに意味を依存しない。
- 小さい画面でもラベルを読める。
- Preview / Edition / region などの条件を誤って一般化しない。
