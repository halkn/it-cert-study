# M1-Q77 Sessionをまたぐ中間table

## 問題

再生成できる中間データを、翌日に別sessionの処理からも使います。長い履歴保持やFail-safeは不要ですが、作成session終了後も明示DROPまでtableを残す必要があります。適切なtable typeはどれですか。

## 選択肢

- A. Temporary table
- B. Transient table
- C. Permanent table
- D. External table

## 正解

B. Transient table

## 正解理由

Transientは明示DROPまで存続し、Fail-safeなしという中間データの要件に適します。

## 各誤答が誤りである理由

- A: Temporaryは作成session終了で削除され、翌日の別session利用を満たしません。
- B: Transientは明示DROPまで存続し、Fail-safeなしという中間データの要件に適します。
- C: 存続は満たしますが、不要なFail-safeを持つため指定した保護・費用要件ではtransientが適します。
- D: External tableは外部stageのファイルを読む方式で、Snowflake内の中間データを保持する要件と異なります。

## 周辺知識

Temporaryとtransientの違いはsession終了後の存続です。
