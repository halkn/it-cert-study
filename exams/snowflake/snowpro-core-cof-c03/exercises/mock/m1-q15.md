# M1-Q15 Humanとserviceの認証分離
- Layer: mock
- Objective IDs: 2.1
- Question type: multiple-select
- Required selections: 4
- Chapter: `textbook/domain-2/01-security-model.md`
- Status: complete
## 問題
Human userにはcorporate SSOとstrong authenticationを要求し、ETL serviceにはinteractive promptを要求せず、interactive applicationには委任tokenを使う設計を4つ選んでください。
## 選択肢
- A. ETL serviceへ共有human passwordとMFA prompt
- B. SAML／OIDC security integration
- C. ETL serviceへkey-pair authentication
- D. IdPまたはauthentication policyでhuman MFAを強制
- E. Interactive applicationへOAuth
- F. ETL serviceへbrowser-based SSOを設定し、operatorのlogin完了を毎回待つ
## 正解
B, C, D, E
## 正解理由
Human federation／MFA、non-interactive service credential、application delegationを分離します。
## 各誤答が誤りである理由
- A: Automationにinteractive promptは適さず、human credentialの共有も避けます。
- B: SAML／OIDC security integrationはSnowflakeとcorporate IdPのfederated authenticationを構成します。
- C: Key-pair authenticationはETL serviceにinteractive promptを要求せず、秘密鍵の署名で認証します。
- D: IdPまたはauthentication policyでMFAを要求すると、human userのstrong authentication要件を満たします。
- E: OAuthはinteractive applicationへpasswordではなく限定された委任tokenを渡せます。
- F: Browser-based SSOはoperatorの対話を必要とするため、無人ETL serviceの認証方式に適しません。
## 周辺知識
Authentication policyで許可方式とuser-level overrideを管理できます。
