# M1-Q15 Humanとserviceの認証分離

## 問題
Human userにはcorporate SSOとstrong authenticationを要求し、ETL serviceにはinteractive promptを要求せず、interactive applicationには委任tokenを使う設計を4つ選んでください。
## 選択肢
- A. SAML／OIDC security integration
- B. IdPまたはauthentication policyでhuman MFAを強制
- C. ETL serviceへkey-pair authentication
- D. Interactive applicationへOAuth
- E. ETL serviceへ共有human passwordとMFA prompt
## 正解
A, B, C, D
## 正解理由
Human federation／MFA、non-interactive service credential、application delegationを分離します。
## 各誤答が誤りである理由
- A: SAML／OIDC security integrationはSnowflakeとcorporate IdPのfederated authenticationを構成します。
- B: IdPまたはauthentication policyでMFAを要求すると、human userのstrong authentication要件を満たします。
- C: Key-pair authenticationはETL serviceにinteractive promptを要求せず、秘密鍵の署名で認証します。
- D: OAuthはinteractive applicationへpasswordではなく限定された委任tokenを渡せます。
- E: Automationにinteractive promptは適さず、credential共有も避けます。
## 周辺知識
Authentication policyで許可方式とuser-level overrideを管理できます。
