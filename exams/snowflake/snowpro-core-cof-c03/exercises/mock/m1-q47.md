## 問題

PDFをstageへ置き、file一覧と文書内の金額を別々に扱いたい。正しい説明を2つ選べ。

2つ選んでください。

## 選択肢

- A. directory tableでpathやsize等の一覧metadataを取得できる
- B. 金額の抽出にはhandler等による内容処理が別途必要になる
- C. directory tableでPDF内のkeyを取得し、VARIANT pathで金額を読む
- D. directory tableのmetadataをrefreshし、更新された金額を文書内のfieldとしてSELECTする

## 正解

A, B

## 正解理由

A: fileの一覧を扱う機能である。

B: metadata取得だけでは文書内容を解析しない。

## 各誤答が誤りである理由

- A: 正しい。fileの一覧を扱う機能である。
- B: 正しい。metadata取得だけでは文書内容を解析しない。
- C: 誤り。directory tableはfile metadataであり本文内のkeyを自動抽出しない。
- D: 誤り。metadataのrefreshはfileの一覧情報を更新する処理であり、PDF本文を解析して金額のfieldを生成するものではない。
