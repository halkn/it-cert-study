## 問題

あるteamはSnowflake objectとStreamlit applicationの変更をGitでreviewし、承認後にCI runnerから同一手順でdevelopmentとproductionへdeployしたいと考えています。最適な中心toolはどれですか。

## 選択肢

- A. Snowflake CLIとversion管理されたproject／SQL file
- B. 個人のSnowsightで記憶に基づき毎回clickする
- C. warehouseを大きくする
- D. secure viewを作成する

## 正解

A. Snowflake CLIとversion管理されたproject／SQL file

## 正解理由

CLIはSQLとdeveloper workloadをcommandから管理でき、fileをGit reviewしてCIで反復実行する要件に合います。

## 各誤答が誤りである理由

- A: 正解です。
- B: 個人の手作業はreview可能な変更記録と環境間の再現性を満たしません。
- C: warehouse sizeはcompute能力でありdeployment workflowではありません。
- D: secure viewはdata privacyのためのobjectで、application deployment toolではありません。

## 周辺知識

環境ごとのconnectionやsecretは安全なsecret storeで分離し、repositoryへ保存しません。
