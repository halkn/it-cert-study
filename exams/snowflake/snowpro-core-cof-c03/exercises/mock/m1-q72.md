# M1-Q72 再利用する処理objectの選定

## 問題

受注処理で、SELECTの式から呼ぶ税額計算と、作業tableの作成・更新を含む複数stepの処理を別々に再利用したいと考えています。対応として適切なものを2つ選んでください。

## 選択肢

- A. 税額計算をUDFとして定義する
- B. 複数stepの処理をfile formatとして定義する
- C. 税額計算をpipeとして定義する
- D. 複数stepの処理をstored procedureとして定義する

## 正解

A. 税額計算をUDFとして定義する
D. 複数stepの処理をstored procedureとして定義する

## 正解理由

UDFはqueryの式として呼び、計算した値を返す用途に適します。 Stored procedureはDDL・DMLを含む手続きをまとめ、CALLで実行する用途に適します。

## 各誤答が誤りである理由

- A: UDFはqueryの式として呼び、計算した値を返す用途に適します。
- B: File formatはファイルの解釈規則で、DDLやDMLの手順をまとめません。
- C: PipeはSnowpipeのファイル取り込み定義で、SELECT式の税額計算ではありません。
- D: Stored procedureはDDL・DMLを含む手続きをまとめ、CALLで実行する用途に適します。

## 周辺知識

UDFとprocedureは言語だけでなく、式としての計算か手続きかで選びます。
