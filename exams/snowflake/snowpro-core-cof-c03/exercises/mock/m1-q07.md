## 問題
account全体のsession timeout既定は維持しつつ、あるservice userの新規sessionだけ別の既定値にしたいと考えています。最も適切なlevelはどれですか。
## 選択肢
- A. Account
- B. User
- C. Session
- D. Warehouse
## 正解
B. User
## 正解理由
Session parameterをuser levelで設定すると、account defaultをそのuserの新規session向けにoverrideできます。
## 各誤答が誤りである理由
- A: Account levelでは全userの新規sessionに使う既定値を変えるため、特定service userだけという影響範囲を超えます。
- B: User levelのsession parameterはaccount既定値を特定userの新規session向けにoverrideできるため、影響範囲が要件と一致します。
- C: Session levelは現在のsessionだけを変更し、そのuserが今後作る新規sessionの既定値にはなりません。
- D: Warehouse levelに設定できるparameterもありますが、userごとのsession timeout既定値を設定するlevelではありません。
## 周辺知識
current sessionだけ変えるなら`ALTER SESSION`、account全体のdefaultなら`ALTER ACCOUNT`を使います。
