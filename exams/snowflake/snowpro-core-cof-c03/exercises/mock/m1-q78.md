## 問題

すでにcloud storageにあるCSVファイルを、Snowflake tableへロードせず、外部stage上のファイルmetadataに基づく読取り専用のtableとして参照したいと考えています。Iceberg形式への変換やsnapshot管理は今回不要です。選ぶobjectはどれですか。

## 選択肢

- A. Dynamic Table
- B. Transient table
- C. Iceberg table
- D. External table

## 正解

D. External table

## 正解理由

External tableはexternal stageのファイルをmetadataに基づいてread-onlyでqueryします。

## 各誤答が誤りである理由

- A: Dynamic TableはSELECT結果を保持しrefreshするもので、指定された外部ファイルの読取り専用インターフェースではありません。
- B: TransientはSnowflake内で保持するtableで、外部CSVの直接参照とは異なります。
- C: Icebergはopen table formatのmetadata等を使う方式で、今回のCSVファイル参照とは異なります。
- D: External tableはexternal stageのファイルをmetadataに基づいてread-onlyでqueryします。

## 周辺知識

保存場所だけでなく、ファイル参照とopen table formatの管理方式を区別します。
