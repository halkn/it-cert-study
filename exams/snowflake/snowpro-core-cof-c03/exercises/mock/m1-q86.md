# M1-Q86 接続元と認証方式を別々に制御する

- Layer: mock
- Objective IDs: 2.1
- Question type: multiple-select
- Required selections: 2
- Chapter: `textbook/domain-2/01-security-model.md`
- Status: complete

## 問題

セキュリティチームは、human userの接続元を会社のnetworkへ限定し、password loginにはMFAを要求したいと考えています。要件への対応を2つ選んでください。

## 選択肢

- A. RoleへtableのSELECTをgrantして接続元を限定する
- B. Network policyを対象へactivateして許可する接続元を制御する
- C. Authentication policy等でpassword loginのMFA要件を設定する
- D. Warehouseへresource monitorを割り当てて認証方式を制御する

## 正解

B. Network policyを対象へactivateして許可する接続元を制御する
C. Authentication policy等でpassword loginのMFA要件を設定する

## 正解理由

Network policyは許可・拒否するnetwork trafficを制御し、対象へactivateして適用します。 Authentication policy／MFAは本人確認の方式・要件を制御し、network制限とは別に設定します。

## 各誤答が誤りである理由

- A: SELECTはobjectへのauthorizationで、接続元networkの制御ではありません。
- B: Network policyは許可・拒否するnetwork trafficを制御し、対象へactivateして適用します。
- C: Authentication policy／MFAは本人確認の方式・要件を制御し、network制限とは別に設定します。
- D: Resource monitorはwarehouseのcredit監視・停止で、loginの認証方式を決めません。

## 周辺知識

認証、network制御、object privilegeは異なる境界です。
