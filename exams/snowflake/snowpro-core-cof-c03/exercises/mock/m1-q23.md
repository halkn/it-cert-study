# M1-Q23 Data quality alert

## 問題
Change trackingが有効なevent tableへ新しいerror rowが到着したときだけconditionを評価し、該当時にwebhookへ送信したい場合に必要なものを3つ選んでください。
## 選択肢
- A. Alert on new data
- B. 1分ごとのscheduled taskでtable全体を再scan
- C. Conditionとaction
- D. Webhook notification integration
- E. Email notification integrationだけ
## 正解
A, C, D
## 正解理由
New data alertが新規rowを評価し、actionからnotificationを送ります。
## 各誤答が誤りである理由
- A: Alert on new dataは新しいerror rowが現れたことを契機に、その追加分へconditionを評価します。
- B: Scheduled taskによる全件scanはpollingであり、新しいrowが到着したときだけ評価する要件から外れます。
- C: Conditionがerrorを判定し、actionがnotification送信procedureを実行します。
- D: Webhook notification integrationはactionから外部webhookへmessageを配送する設定を提供します。
- E: Email integrationはemail配送用であり、指定されたwebhook endpointへの配送設定を提供しません。
## 周辺知識
Alert on new dataのsource objectではchange trackingが必要です。本問では有効化済みの前提を問題文に明記しています。
