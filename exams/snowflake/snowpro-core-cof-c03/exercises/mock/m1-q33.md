# M1-Q33 外部API呼び出しの構成

## 問題
SQLのqueryから社外の住所正規化APIを呼び出し、結果を列として得たいという要件があります。必要な構成はどれですか。
## 選択肢
- A. storage integrationとexternal stage
- B. notification integrationとalert
- C. API integrationとexternal function
- D. security integrationとnetwork policy

## 正解

C

## 正解理由
external functionはSnowflakeの外で実行される利用者定義関数で、呼び出し先のHTTPS proxy serviceはAPI integrationの`API_ALLOWED_PREFIXES`で許可します。
## 各誤答が誤りである理由
- A: cloud storage上のファイルを扱う構成で、API呼び出しには使いません。
- B: notification integrationはmessage配送のための設定です。
- C: API integrationが呼び出し先を許可し、external functionがSQLからの呼び出し口になります。
- D: security integrationは認証・認可、network policyは接続元の制御に使います。

## 周辺知識
UDFやprocedureのhandlerから外部network locationへ出る通信には、`ALLOWED_NETWORK_RULES`が必須のexternal access integrationを使います。
