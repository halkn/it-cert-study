## 問題

Procedureのhandlerで発生したlogやtraceを保存し、後でSQLで調べたいと考えています。Query実行時間の履歴だけではなく、処理内部のtelemetryを対象にする保存先はどれですか。

## 選択肢

- A. QUERY_HISTORY viewだけ
- B. LOGIN_HISTORY viewだけ
- C. Event table
- D. WAREHOUSE_METERING_HISTORY viewだけ

## 正解

C. Event table

## 正解理由

Event tableはlog、trace、metric等のtelemetryを保持し、設定した収集結果を調査できます。

## 各誤答が誤りである理由

- A: Query履歴はqueryの実行情報で、handlerのlog・traceの保存先そのものではありません。
- B: LOGIN_HISTORYはloginの調査用であり、handlerのlog・traceを保持する保存先ではありません。
- C: Event tableはlog、trace、metric等のtelemetryを保持し、設定した収集結果を調査できます。
- D: WAREHOUSE_METERING_HISTORYはwarehouse使用量の履歴であり、handlerの内部telemetryを保持する保存先ではありません。

## 周辺知識

Telemetryの有効化・level設定と、保存先への参照権限も確認します。
