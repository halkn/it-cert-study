## 問題
Finance analystへ`FIN_DB.REPORTING.REVENUE`の参照だけを付与する設計として適切なものを3つ選んでください。
## 選択肢
- A. DatabaseとschemaのUSAGE、tableのSELECTをaccess roleへgrantする
- B. Access roleをFINANCE_ANALYST functional roleへgrantする
- C. FINANCE_ANALYSTをanalyst userへgrantする
- D. ACCOUNTADMINをanalyst userへgrantする
## 正解
A, B, C
## 正解理由
Object privilegeをaccess roleへまとめ、job function role経由でuserへ届けます。
## 各誤答が誤りである理由
- A: 正解です。
- B: 正解です。
- C: 正解です。
- D: Account最上位権限でありleast privilegeに反します。
## 周辺知識
Object ownerがaccessを委任する部分はDAC、role経由の割当はRBACです。
