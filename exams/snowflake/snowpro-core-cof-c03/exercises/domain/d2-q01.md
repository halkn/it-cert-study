# D2-Q01 Least-privilege role設計

## 問題
Finance analystへ`FIN_DB.REPORTING.REVENUE`の参照だけを付与する設計として適切なものを3つ選んでください。
## 選択肢
- A. DatabaseとschemaのUSAGE、tableのSELECTをaccess roleへgrantする
- B. Access roleをFINANCE_ANALYST functional roleへgrantする
- C. FINANCE_ANALYSTをanalyst userへgrantする
- D. Tableの`OWNERSHIP`をaccess roleへgrantする
## 正解
A, B, C
## 正解理由
Object privilegeをaccess roleへまとめ、job function role経由でuserへ届けます。
## 各誤答が誤りである理由
- A: Containerの`USAGE`とtableの`SELECT`をaccess roleへ集約すると、参照に必要な最小privilegeだけを定義できます。
- B: Access roleをfunctional roleへgrantすると、object accessとjob functionの責務を分離できます。
- C: Functional roleをuserへgrantすることで、userはjob functionに必要なaccess roleを継承できます。
- D: `OWNERSHIP`は参照だけでなくobjectの管理とgrant委任を可能にするため、参照だけという要件には過剰です。
## 周辺知識
Object ownerがaccessを委任する部分はDAC、role経由の割当はRBACです。
