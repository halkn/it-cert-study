## 問題
SELECTでdesired resultと鮮度を宣言し、dependencyとrefreshをSnowflakeへ委ねたい場合はどれですか。
## 選択肢
- A. Dynamic table
- B. Secure view
- C. External table
- D. File format
## 正解
A. Dynamic table
## 正解理由
Dynamic tableはSELECT結果をmaterializeしtarget lagに従って更新します。
## 各誤答が誤りである理由
- A: 正解です。
- B: privacy保護のview属性です。
- C: external fileのread-only interfaceです。
- D: file解釈規則です。
## 周辺知識
Materialized viewより複雑なpipelineを宣言できますがsupported queryを確認します。
