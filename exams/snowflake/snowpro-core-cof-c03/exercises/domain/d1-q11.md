## 問題
SELECTでdesired resultと鮮度を宣言し、dependencyとrefreshをSnowflakeへ委ねたい場合はどれですか。
## 選択肢
- A. File format
- B. Dynamic table
- C. Secure view
- D. External table

## 正解
B. Dynamic table
## 正解理由
Dynamic tableはSELECT結果をmaterializeしtarget lagに従って更新します。
## 各誤答が誤りである理由
- A: file解釈規則です。
- B: Dynamic tableはSELECT結果をmaterializeしtarget lagに従って更新します。
- C: privacy保護のview属性です。
- D: external fileのread-only interfaceです。

## 周辺知識
