## 問題
Cloud stage上のCSVをloadせずread-onlyでqueryしたい場合のobjectはどれですか。
## 選択肢
- A. Temporary table
- B. Sequence
- C. External table
- D. Dynamic table

## 正解
C. External table
## 正解理由
External tableはexternal stage上fileをtableのようにread-only queryします。
## 各誤答が誤りである理由
- A: Snowflake storageへdataを保持します。
- B: 数列objectです。
- C: External tableはexternal stage上fileをtableのようにread-only queryします。
- D: query結果をrefreshします。

## 周辺知識
Open table formatのtransaction semanticsが必要ならIcebergを比較します。
