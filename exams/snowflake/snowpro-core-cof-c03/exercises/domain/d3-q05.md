# D3-Q05 Stream + task pipelineの構成
- Layer: domain
- Objective IDs: 3.2
- Question type: multiple-select
- Required selections: 2
- Chapter: `textbook/domain-3/02-automated-ingestion.md`
- Status: complete
## 問題
Streamで検知した変更を、変更があるときだけTaskで反映する構成にします。必要な設定を2つ選んでください。
## 選択肢
- A. taskへ`WHEN SYSTEM$STREAM_HAS_DATA('<stream>')`を指定する
- B. 作成したtaskへ`ALTER TASK ... RESUME`を実行する
- C. streamを定期的に`SELECT`してoffsetを進める
- D. streamの`APPEND_ONLY`を`TRUE`にしてoffsetを固定する

## 正解

A, B

## 正解理由
`WHEN`条件で変更がないときの実行をスキップし、`RESUME`でscheduleを有効にします。
## 各誤答が誤りである理由
- A: `WHEN SYSTEM$STREAM_HAS_DATA()`により、変更がないときはcompute資源を使わずにスキップできます。
- B: 作成直後のtaskはsuspendedのため、`RESUME`しないと動きません。
- C: `SELECT`ではoffsetは進みません。offsetが進むのはDMLで消費したときです。
- D: `APPEND_ONLY`は追跡する変更の種類を絞る設定で、offsetを固定するものではありません。

## 周辺知識
offsetが長期間進まないと、`MAX_DATA_EXTENSION_TIME_IN_DAYS`（既定14日）の延長期間を超えた時点でstreamはstaleになります。
