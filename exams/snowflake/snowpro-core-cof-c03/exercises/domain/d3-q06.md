# D3-Q06 Snowpipeのcostと監視

## 問題
Snowpipeで継続ロードしている構成のcostと結果を確認します。正しい説明を2つ選んでください。
## 選択肢
- A. Snowpipeが使うcomputeはResource Monitorで停止できる
- B. Snowpipeの使用量は`PIPE_USAGE_HISTORY`で確認できる
- C. Snowpipeによるロード結果は`COPY_HISTORY`で確認できる
- D. Snowpipeによるロード結果は`LOAD_HISTORY`で確認できる

## 正解

B, C

## 正解理由
Snowpipeの使用量は`PIPE_USAGE_HISTORY`、ロード結果は`COPY_HISTORY`で確認します。
## 各誤答が誤りである理由
- A: Resource Monitorはuser-managed warehouseを対象とする機能で、Snowpipeのcomputeは制御できません。
- B: `PIPE_USAGE_HISTORY`はSnowpipeが消費したcreditとbytesを提供します。
- C: `COPY_HISTORY`は`COPY INTO`とSnowpipeの両方のロード履歴を返します。
- D: `LOAD_HISTORY`は`COPY INTO`のみを対象とし、Snowpipeのロードを返しません。

## 周辺知識
Snowpipeはserverlessですが課金は発生します。warehouseを自分で用意・起動しなくてよいという点が違いです。
