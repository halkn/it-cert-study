## 問題
既存のSpark基盤を持つチームが、Sparkのjobを保ったままSnowflakeのデータを読み書きします。最も適した部品はどれですか。
## 選択肢
- A. Snowflake Connector for Spark
- B. Snowpark DataFrame API
- C. Snowflake Connector for Kafka
- D. Snowflake Python API（`snowflake.core`）

## 正解

A

## 正解理由
Spark基盤を維持したままSnowflakeと連携するにはSpark connectorを使います。内部でJDBC driverを使い、query pushdownで一部の処理をSnowflake側へ寄せられます。
## 各誤答が誤りである理由
- A: Spark clusterを保ったままSnowflakeを読み書きする用途に合います。
- B: SnowparkはSpark clusterを使わずSnowflake内で処理する選択肢で、既存Spark jobをそのまま活かす要件には合いません。
- C: Kafka connectorはKafkaのtopicをtableへ取り込むための部品です。
- D: Snowflake Python APIはresource管理のための層で、データ処理の実行基盤ではありません。

## 周辺知識
Spark connectorではSpark UDFをpushdownできません。Snowflake内で完結させたい場合はSnowparkが候補になります。
