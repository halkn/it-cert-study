# D2-Q05 Security postureとkey control
- Layer: domain
- Objective IDs: 2.2
- Question type: multiple-select
- Required selections: 3
- Chapter: `textbook/domain-2/02-data-governance.md`
- Status: complete
## 問題
Account設定をrecommendationへ継続照合し、Snowflake-managed key lifecycleを確認し、customerがcloud KMS keyもcontrolしたい場合に選ぶものを3つ選んでください。
## 選択肢
- A. Trust Center
- B. Tri-Secret Secure
- C. Hierarchical key modelとautomatic rotation
- D. Query result cache
- E. Snowpipe
## 正解
A, B, C
## 正解理由
Trust Centerがsecurity posture、Snowflake key hierarchyが通常のkey lifecycle、Tri-Secret SecureがCMKとのdual-key modelを提供します。
## 各誤答が誤りである理由
- A: 正解です。
- B: 正解です。
- C: 正解です。
- D: Query結果再利用でありsecurity評価ではありません。
- E: File ingestion機能です。
## 周辺知識
Tri-Secret SecureはBusiness Critical以上で、CMK availabilityの運用責任が増えます。
