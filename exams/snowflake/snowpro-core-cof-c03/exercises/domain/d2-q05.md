# D2-Q05 Security postureとkey control
- Layer: domain
- Objective IDs: 2.2
- Question type: multiple-select
- Required selections: 3
- Chapter: `textbook/domain-2/02-data-governance.md`
- Status: complete
## 問題
Account設定をrecommendationへ継続照合し、Snowflake-managed key lifecycleを確認し、customerがcloud KMS keyもcontrolしたい場合に選ぶものを3つ選んでください。
## 選択肢
- A. Trust Center
- B. Tri-Secret Secure
- C. Hierarchical key modelとautomatic rotation
- D. Periodic rekeyingだけを有効にする
- E. CMKでraw dataを直接暗号化し、Snowflake-managed keyを使わない
## 正解
A, B, C
## 正解理由
Trust Centerがsecurity posture、Snowflake key hierarchyが通常のkey lifecycle、Tri-Secret SecureがCMKとのdual-key modelを提供します。
## 各誤答が誤りである理由
- A: Trust Centerはscannerでaccount設定をrecommendationへ継続照合し、findingを示します。
- B: Tri-Secret SecureはSnowflake-managed keyとCMKを組み合わせ、customer側のkey controlを追加します。
- C: Hierarchical key modelとautomatic rotationはSnowflakeが通常管理するkey lifecycleを説明します。
- D: Periodic rekeyingは既存dataを新しいkeyで再暗号化しますが、security posture評価やCMK controlは提供しません。
- E: Tri-Secret Secureのcomposite keyはaccount key hierarchyを保護し、raw dataをCMKだけで直接暗号化する構成ではありません。
## 周辺知識
Tri-Secret SecureはBusiness Critical以上で、CMK availabilityの運用責任が増えます。
