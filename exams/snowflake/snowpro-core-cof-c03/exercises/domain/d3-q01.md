# D3-Q01 Stage選定と権限の組合せ

## 問題
複数チームがS3上の同じprefixからロードし、cloud側の資格情報をSQL文へ書かない構成にします。正しい設計を2つ選んでください。
## 選択肢
- A. storage integrationを参照するexternal stageを作成する
- B. 各userのuser stage（`@~`）へファイルをコピーして共有する
- C. stageを使うroleへ、そのexternal stageの`USAGE`をgrantする
- D. external stageに`READ`をgrantし、`USAGE`は使わない

## 正解

A, C

## 正解理由
External stageはstorage integrationを参照することで資格情報を定義へ書かずに済みます。External stageの利用にはprivilegeとして`USAGE`をgrantします。
## 各誤答が誤りである理由
- A: storage integrationを参照すると、鍵やtokenをstage定義へ書かずに済み、cloud側の権限設定を1か所へ集約できます。
- B: user stageは各userの専用領域で共有できません。
- C: External stageの参照には`USAGE`が必要で、`USAGE`は`READ`と`WRITE`を含みます。
- D: `READ`はinternal stageに対して使うprivilegeです。

## 周辺知識
1つのstorage integrationを複数のexternal stageで共有できます。integrationを使うroleにはintegrationへの`USAGE`も必要です。
