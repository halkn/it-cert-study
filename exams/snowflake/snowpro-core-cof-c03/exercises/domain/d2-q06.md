# D2-Q06 Condition判定とmessage配送

## 問題
Warehouse creditが基準を超えたか30分ごとに調べ、Slackへmessageを送る構成要素を2つ選んでください。
## 選択肢
- A. Scheduled alert
- B. Webhook notification integration
- C. Row access policy
- D. Database failover group
## 正解
A, B
## 正解理由
Alertがconditionを評価し、notification integrationがmessageを配送します。
## 各誤答が誤りである理由
- A: 正解です。
- B: 正解です。
- C: Result rowをfilterします。
- D: Disaster recovery用です。
## 周辺知識
Hard quota enforcementにはResource Monitor triggerを使います。
