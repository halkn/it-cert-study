# D2-Q06 Condition判定とmessage配送

## 問題
Warehouse creditが基準を超えたか30分ごとに調べ、Slackへmessageを送る構成要素を2つ選んでください。
## 選択肢
- A. Alert on new data
- B. Scheduled alert
- C. Webhook notification integration
- D. Resource Monitorの`NOTIFY` triggerだけ

## 正解

B, C

## 正解理由
Alertがconditionを評価し、notification integrationがmessageを配送します。
## 各誤答が誤りである理由
- A: Alert on new dataは新しいrowの到着を契機に評価するため、30分ごとの定期評価という要件と異なります。
- B: Scheduled alertは30分ごとのscheduleでcredit dataを評価し、trueならactionを実行できます。
- C: Webhook notification integrationはalert actionからSlack endpointへmessageを配送する設定を保持します。
- D: Resource Monitorの`NOTIFY`はquota thresholdの通知ですが、この選択肢だけではSlack webhookへの配送を構成できません。

## 周辺知識
Hard quota enforcementにはResource Monitor triggerを使います。
