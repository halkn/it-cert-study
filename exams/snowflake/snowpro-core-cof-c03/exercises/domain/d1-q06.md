# D1-Q06 object名を変数で指定する

## 問題
CLI scriptで`SET target='ORDERS'`とした後、変数をtable identifierとして安全に解釈させる構文はどれですか。
## 選択肢
- A. `SELECT * FROM $target`
- B. `SELECT * FROM IDENTIFIER($target)`
- C. `SELECT * FROM CURRENT_ROLE()`
- D. `SELECT * FROM PARAMETER($target)`
## 正解
B. `SELECT * FROM IDENTIFIER($target)`
## 正解理由
SQL variableをobject identifierとして使うときは`IDENTIFIER()`で明示します。
## 各誤答が誤りである理由
- A: `$target`はliteral参照でありFROMのidentifier用途を明示しません。
- B: 正解です。
- C: current roleを返すcontext functionでtable名を解決しません。
- D: その用途の構文ではありません。
## 周辺知識
SQL variableはsession限定で、session終了時に破棄されます。
