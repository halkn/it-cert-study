## 問題

二社が顧客明細を自由に公開せず、許可した集計だけを共同実行したいと考えています。最も適切な設計はどれですか。

## 選択肢

- A. Public listingで全顧客tableを無料公開する
- B. Direct shareで全顧客tableへSELECTを与える
- C. Data Clean Roomで提供データ・分析・出力を制約する
- D. Private listingにすれば分析templateは不要になる

## 正解

C

## 正解理由

Clean Roomは提供データと分析・結果の制約を設計する用途です。

## 各誤答が誤りである理由

- A: 全tableの公開は分析・出力の制限になりません。
- B: Table SELECTだけでは許可した集計への制約を実装しません。
- C: Clean Roomは提供データと分析・結果の制約を設計する用途です。
- D: Privateは公開先の軸で、分析内容の制約を代替しません。

## 周辺知識

Clean Roomの名前だけで明細禁止が実装されるわけではありません。
