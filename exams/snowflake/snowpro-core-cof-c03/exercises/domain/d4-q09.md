## 問題

PDFの内容から金額を抽出して集計したい。最初の設計判断はどれか。

1つ選んでください。

## 選択肢

- A. すべてのPDFをVARIANT pathだけで自動解析する
- B. QUALIFYを付ければfileの内容がSQL列へ自動変換される
- C. directory metadataとfile内容の抽出を分け、内容を処理するhandler等を用意する
- D. directory tableのSIZEを文書内の金額としてSUMする

## 正解

C

## 正解理由

C: file一覧だけでは業務値は得られない。

## 各誤答が誤りである理由

- A: 誤り。stageへ置くだけでJSON fieldにはならない。
- B: 誤り。QUALIFYはwindow後filterであり内容抽出ではない。
- C: 正しい。file一覧だけでは業務値は得られない。
- D: 誤り。file sizeと文書内金額は違う。
