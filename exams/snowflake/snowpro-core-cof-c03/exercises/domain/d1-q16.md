# D1-Q16 Organization階層とschema object

## 問題

企業が複数regionにaccountを持ち、各accountにwarehouseと業務databaseを設けています。ORDER_SEQというsequenceと注文tableを同じschemaに作る設計について、階層の説明として正しいものを2つ選んでください。

## 選択肢

- A. Organizationは企業のaccountを結び付ける管理単位であり、warehouseはaccount-level objectである
- B. Warehouseはdatabaseの配下にあり、完全修飾table名にはwarehouse名を含める
- C. Sequenceとtableはschema-level objectで、DB.SCHEMA.OBJECTという名前空間を使う
- D. Organizationを変えれば、USE SCHEMAで現在のdatabaseを指定しなくても別accountのtableへ直接接続できる

## 正解

A, C

## 正解理由

Organizationは複数accountを包含し、warehouseはdatabase・schemaに属さないaccount-level objectです。 Sequenceは数列を生成するschema objectで、tableと同じdatabase・schema階層に置かれます。

## 各誤答が誤りである理由

- A: Organizationは複数accountを包含し、warehouseはdatabase・schemaに属さないaccount-level objectです。
- B: Warehouseはaccount-level compute objectで、tableの完全修飾名の一部ではありません。
- C: Sequenceは数列を生成するschema objectで、tableと同じdatabase・schema階層に置かれます。
- D: Sessionは接続先account内のcontextを持ちます。USE SCHEMAは別accountへの接続切替ではありません。

## 周辺知識

Databaseとschemaはobject名の解決先、warehouseは処理用computeです。名前空間と実行資源を分けて確認します。
