# D1-Q04 interfaceとsession context

- Layer: domain

- Status: complete

## 問題

同じuserがSnowsightとSnowflake CLIから同じSQLを実行しましたが、参照objectとcompute costの帰属が異なりました。直接確認すべきcontextを2つ選んでください。

## 選択肢

- A. current database／schema
- B. current warehouse
- C. browserのwindow size
- D. local fileの文字色

## 正解

A, B

## 正解理由

database／schemaは非修飾object名の解決先を、warehouseはqueryを処理するcomputeを決めます。interfaceごとにsessionが異なるためcontextも同一とは限りません。

## 各誤答が誤りである理由

- A: 正解です。
- B: 正解です。
- C: browser表示サイズはSnowflake objectの名前解決やwarehouse選択を変えません。
- D: editor themeは実行contextではありません。

## 周辺知識

`CURRENT_ROLE()`も確認します。roleが異なると同じobjectでも操作可否が変わります。
