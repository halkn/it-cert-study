## 問題
要件とintegrationの正しい対応を3つ選んでください。
## 選択肢
- A. external stageからS3のファイルを読む: storage integration
- B. SQLから外部のHTTPS APIを呼び出す: API integration
- C. UDFのhandlerから外部endpointへ通信する: external access integration
- D. cloud storageの資格情報を保持する: notification integration

## 正解

A, B, C

## 正解理由
対象がcloud storageならstorage、HTTPS proxy serviceならAPI、UDF handlerからの外向き通信ならexternal accessです。
## 各誤答が誤りである理由
- A: external stageはstorage integrationを参照して資格情報を得ます。
- B: external functionの呼び出し先はAPI integrationで許可します。
- C: external access integrationは`ALLOWED_NETWORK_RULES`が必須で、handlerからの外部通信に使います。
- D: notification integrationはqueue、email、webhookへの通知配送に使います。

## 周辺知識
integrationはいずれもaccount-level objectで、作成には`CREATE INTEGRATION`が必要です。既定ではACCOUNTADMINだけがこのprivilegeを持ちます。
