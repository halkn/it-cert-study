## 問題
Snowflake内のGit repository cloneで、`main` branchのファイルを参照するpathはどれですか。
## 選択肢
- A. `@my_repo/main/`
- B. `@my_repo:main`
- C. `@my_repo/branches/main/`
- D. `@my_repo/refs/heads/main/`

## 正解

C

## 正解理由
参照pathは`@<repo>/branches/<branch>/`の形です。tagは`@<repo>/tags/<tag>/`、commitは`@<repo>/commits/<hash>/`で参照します。
## 各誤答が誤りである理由
- A: `branches`の階層が必要です。
- B: コロンで区切る記法は使いません。
- C: stageと同じ記法で、`branches`配下にbranch名を置きます。
- D: Gitの内部参照名をそのまま使う形式ではありません。

## 周辺知識
`ALTER GIT REPOSITORY ... FETCH`でremoteの内容をcloneへ取り込みます。`EXECUTE IMMEDIATE FROM`と組み合わせると、repository内のSQLスクリプトを実行できます。
