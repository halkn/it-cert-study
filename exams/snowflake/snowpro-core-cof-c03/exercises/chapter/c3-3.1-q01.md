## 問題
複数のuserが複数のtableへ定期的にファイルをロードする運用で、roleへ権限を付け替えられるinternal stageはどれですか。
## 選択肢
- A. User stage（`@~`）
- B. Table stage（`@%orders`）
- C. Named internal stage
- D. External stage

## 正解

C

## 正解理由
Named internal stageはschema-level objectとして作成でき、roleへの権限付与・取消や所有権の移譲ができます。複数user・複数tableで継続的にロードする用途で推奨されます。
## 各誤答が誤りである理由
- A: User stageは各userの専用領域で、他userと共有できず、変更や削除もできません。
- B: Table stageは1つのtable専用で、ファイル操作はそのtableのOWNERSHIP保持者に限られます。
- C: Named internal stageはschema-level objectで、権限付与と所有権移譲ができる唯一のinternal stageです。
- D: External stageは外部cloud storage上の場所を指すため、internal stageの選択肢ではありません。

## 周辺知識
User stageとtable stageはaccountやtableに付随する領域で、`CREATE STAGE`では作成しません。
