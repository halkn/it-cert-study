## 問題
新しいclient connectionで推奨されるaccount identifierの構成はどれですか。
## 選択肢
- A. Organization nameとaccount name
- B. User nameとrole name
- C. Database nameとschema name
- D. Warehouse nameだけ
## 正解
A
## 正解理由
推奨identifierはorganization名とaccount名を組み合わせます。
## 各誤答が誤りである理由
- A: Organization nameとaccount nameの組合せは、organizationを越えてaccountを識別する推奨形式です。
- B: Identityとauthorization contextでありaccountを識別しません。
- C: Account内のdatabase object contextです。
- D: Compute object名であり接続先accountを一意にしません。
## 周辺知識
Account locatorを使うlegacy形式もありますが推奨形式ではありません。
