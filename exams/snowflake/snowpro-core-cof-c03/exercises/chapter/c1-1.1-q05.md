# C1-1.1-Q05 query処理と3層の対応

## 問題

Snowflakeへ送信されたqueryの処理について、正しい対応を3つ選んでください。

## 選択肢

- A. Cloud Services — authenticationとauthorizationを確認する
- B. Cloud Services — metadataを参照してqueryをparse・optimizeする
- C. Virtual Warehouse — 実行計画に従ってtable scanやjoinを処理する
- D. Database Storage — 利用者のroleを認証する
- E. Snowflake Edition — queryごとの実行計画を保持して処理する

## 正解

A、B、C

## 正解理由

Cloud Servicesがaccess確認、metadata管理、queryのparse／optimizationを調整し、Virtual Warehouseが実行計画に従うcompute処理を担います。

## 各誤答が誤りである理由

- A: 正しい対応です。
- B: 正しい対応です。
- C: 正しい対応です。
- D: Database Storageの主目的は永続dataの保持であり、利用者の認証はCloud Servicesが担います。
- E: Editionは利用可能な機能やservice levelを定める区分であり、queryを処理するlayerではありません。

## 周辺知識

cacheなどによりstorage scanが省略される場合もありますが、3層の基本的な責務は変わりません。
