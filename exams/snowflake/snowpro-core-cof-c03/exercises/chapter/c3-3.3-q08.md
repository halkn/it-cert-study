## 問題
private repositoryに対してGit integrationを構成するために必要なobjectを3つ選んでください。
## 選択肢
- A. 認証情報を保持するsecret
- B. `API_PROVIDER = git_https_api`のAPI integration
- C. Git repository object
- D. external stageとstorage integration

## 正解

A, B, C

## 正解理由
Git integrationはsecret、`git_https_api`を指定したAPI integration、Git repository objectの3つで構成します。
## 各誤答が誤りである理由
- A: secretはrepositoryへの認証情報（tokenやOAuth）を保持します。
- B: API integrationは`API_ALLOWED_PREFIXES`で対象repositoryのURL接頭辞を、`ALLOWED_AUTHENTICATION_SECRETS`で使えるsecretを限定します。
- C: Git repository objectが`ORIGIN`、`API_INTEGRATION`、`GIT_CREDENTIALS`を結び付けます。
- D: external stageとstorage integrationはcloud storage向けで、Git integrationには使いません。

## 周辺知識
Git repositoryとsecretはschema-level object、API integrationはaccount-level objectです。認証方式は、認証なし、token、OAuth flowから選べます。
