## 問題

repository内のSQL fileをCI/CDから実行し、Streamlit applicationもcommandでdeployしたい場合に最も適したtoolはどれですか。

## 選択肢

- A. Snowsight chart
- B. Snowflake CLI
- C. Materialized view
- D. Query Profile

## 正解

B. Snowflake CLI

## 正解理由

Snowflake CLIは` snow `commandからSQLを実行し、Streamlitを含むdeveloper workloadを管理できるため、scriptとCI/CDに適します。

## 各誤答が誤りである理由

- A: chartはquery結果の可視化でありdeployment toolではありません。
- B: 正解です。
- C: materialized viewはquery結果を保持・保守するdatabase objectです。
- D: Query Profileはquery実行の分析に使い、applicationをdeployしません。

## 周辺知識

connection fileにsecretを平文で置いてrepositoryへcommitしないようにします。CLIでも実行userのroleとprivilegeが適用されます。
