## 問題
PythonからSQL文を書かずにdatabase、warehouse、taskなどのobjectを作成・管理したい場合に使うものはどれですか。
## 選択肢
- A. Snowflake Python API（`snowflake.core`）
- B. Snowflake Connector for Python
- C. Snowpark DataFrame API
- D. JDBC Driver

## 正解

A

## 正解理由
Snowflake Python APIは、SQL文の文字列を書かずにSnowflakeのresourceをPython objectとして操作するためのlibraryです。
## 各誤答が誤りである理由
- A: `snowflake.core`はresource管理を宣言的に行う層で、DevOpsの自動化に向きます。
- B: Connector for PythonはSQL文の文字列を書いて実行するdriverです。
- C: SnowparkはDataFrameでデータ処理を記述する層で、resource管理が主目的ではありません。
- D: JDBCはJava向けdriverです。

## 周辺知識
3つは「SQL文字列を書くか」「resourceを宣言的に扱うか」「データを処理するか」で役割が分かれます。
