## 問題
Storage integrationを使う主な理由はどれですか。
## 選択肢
- A. external stage上のファイルを自動的にtableへロードするため
- B. external stageのファイルを暗号化するため
- C. cloud providerの資格情報をSQL文やstage定義へ書かずに済ませるため
- D. cloud storageのファイルにmetadata catalogを付けるため

## 正解

C

## 正解理由
公式docsはintegrationの目的を「secret keyやaccess tokenといったcloud providerの資格情報を明示的に渡す必要をなくすこと」と説明しています。
## 各誤答が誤りである理由
- A: 自動ロードはSnowpipeの役割です。
- B: 暗号化は`ENCRYPTION`の設定やcloud storage側の機能で扱います。
- C: 資格情報をintegration objectへ集約し、stage定義やSQL文へ書かずに済ませます。
- D: metadata catalogを提供するのはdirectory tableです。

## 周辺知識
1つのstorage integrationを複数のexternal stageで共有できます。`DESC INTEGRATION`でAWS IAM roleとの信頼関係に使うexternal IDを取得します。
