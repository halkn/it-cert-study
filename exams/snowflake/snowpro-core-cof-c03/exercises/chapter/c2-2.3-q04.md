## 問題

同じapplication userがfinanceとengineeringのSQLを同じwarehouseで発行します。Queryごとに部門を識別する分類情報はどれですか。

## 選択肢

- A. Warehouseに固定したcost_center object tag
- B. Application userに固定したcost_center object tag
- C. 部門ごとに設定するsessionのQUERY_TAG
- D. WarehouseのRESOURCE_MONITOR parameter

## 正解

C

## 正解理由

QUERY_TAGを部門ごとに変更すると後続queryに部門情報を記録できます。

## 各誤答が誤りである理由

- A: Warehouse全体の分類では、内部で実行するqueryの部門を区別できません。
- B: 同じuserの固定値では部門を区別できません。
- C: QUERY_TAGを部門ごとに変更すると後続queryに部門情報を記録できます。
- D: RESOURCE_MONITORはquotaの監視割当であり、queryの部門分類ではありません。

## 周辺知識

分類の粒度、creditの測定範囲、予測通知と停止の設定を分けて要件へ対応させます。
