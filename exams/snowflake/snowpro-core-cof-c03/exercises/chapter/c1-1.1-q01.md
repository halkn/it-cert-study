## 問題

SnowflakeでSQLを受信し、metadataを参照してqueryをparse・optimizeする主な層はどれですか。

## 選択肢

- A. Virtual Warehouse
- B. Cloud Services
- C. Client driver
- D. Database Storage

## 正解

B. Cloud Services

## 正解理由

Cloud Servicesは認証、metadata管理、queryのparseとoptimizationなど、Snowflake全体を調整するserviceを管理します。

## 各誤答が誤りである理由

- A: Virtual Warehouseは最適化された実行計画に基づくSQL処理を担うcomputeです。
- B: Cloud Servicesは認証、metadata管理、queryのparseとoptimizationなど、Snowflake全体を調整するserviceを管理します。
- C: driverはclientとSnowflakeを接続しますが、Snowflake内部のquery optimizerではありません。
- D: Database Storageの主目的は永続dataの保持です。

## 周辺知識

Cloud Services自体もcompute instance上で動きますが、通常のquery実行に使うユーザー管理のVirtual Warehouseとは役割・管理主体が異なります。
