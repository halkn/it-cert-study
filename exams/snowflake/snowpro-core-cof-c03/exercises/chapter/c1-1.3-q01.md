## 問題
Schema objectではなくaccount-level objectであるものを2つ選んでください。
## 選択肢
- A. Table
- B. File format
- C. Virtual warehouse
- D. Share

## 正解

C, D

## 正解理由
Warehouseとshareはaccount内に存在しますがdatabase／schemaには所属しません。
## 各誤答が誤りである理由
- A: tableはschema objectです。
- B: named file formatはschema objectです。
- C: computeを提供するaccount objectです。
- D: 共有対象を管理するaccount objectです。

## 周辺知識
完全修飾table名は`DB.SCHEMA.TABLE`であり、warehouse名を含みません。
