# C1-1.3-Q01 account objectとschema object

## 問題
Schema objectではなくaccount-level objectであるものを2つ選んでください。
## 選択肢
- A. Virtual warehouse
- B. Share
- C. Table
- D. File format
## 正解
A, B
## 正解理由
Warehouseとshareはaccount内に存在しますがdatabase／schemaには所属しません。
## 各誤答が誤りである理由
- A: 正解です。computeを提供するaccount objectです。
- B: 正解です。共有対象を管理するaccount objectです。
- C: tableはschema objectです。
- D: named file formatはschema objectです。
## 周辺知識
完全修飾table名は`DB.SCHEMA.TABLE`であり、warehouse名を含みません。
