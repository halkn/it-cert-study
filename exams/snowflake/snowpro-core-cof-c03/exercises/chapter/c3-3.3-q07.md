## 問題
SQLから社外の機械学習APIを呼び出したい場合に必要な組合せはどれですか。
## 選択肢
- A. storage integrationとexternal stage
- B. notification integrationとalert
- C. security integrationとnetwork policy
- D. API integrationとexternal function

## 正解

D

## 正解理由
external functionはSnowflakeの外で実行される利用者定義関数で、呼び出し先のHTTPS proxy serviceはAPI integrationで許可します。
## 各誤答が誤りである理由
- A: storage integrationとexternal stageはcloud storage上のファイルを扱う組合せです。
- B: notification integrationはmessage配送のための設定です。
- C: security integrationは認証・認可、network policyは接続元の制御に使います。
- D: API integrationが呼び出し先を許可し、external functionがSQLからの呼び出し口になります。

## 周辺知識
external functionを使うと、データをexportしてから外部serviceへ渡し、結果をimportし直す手間がなくなります。
