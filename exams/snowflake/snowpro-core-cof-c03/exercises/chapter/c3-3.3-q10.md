## 問題
UDFやstored procedureのhandlerから外部のnetwork locationへ通信させるために使うintegrationはどれですか。
## 選択肢
- A. External access integration
- B. Storage integration
- C. Notification integration
- D. Security integration

## 正解

A

## 正解理由
External access integrationは、UDFやprocedureのhandlerから外部network locationへアクセスするためのintegrationで、`ALLOWED_NETWORK_RULES`が必須です。
## 各誤答が誤りである理由
- A: handlerからの外向き通信を許可する目的のintegrationです。
- B: storage integrationはcloud storageへのアクセスに使います。
- C: notification integrationはqueue、email、webhookへの通知配送に使います。
- D: security integrationは外部IdPやOAuth clientとの認証・認可に使います。

## 周辺知識
integrationはいずれもaccount-level objectで、作成には`CREATE INTEGRATION`と種類ごとの権限が必要です。
