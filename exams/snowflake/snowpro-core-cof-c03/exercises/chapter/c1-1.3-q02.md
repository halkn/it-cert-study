## 問題
新着fileへ適用するCOPY statementを保持し、Snowpipeによる継続loadを定義するobjectはどれですか。
## 選択肢
- A. Stage
- B. File format
- C. Pipe
- D. Sequence
## 正解
C. Pipe
## 正解理由
PipeはSnowpipeがfileをtableへloadするCOPY statementを保持します。
## 各誤答が誤りである理由
- A: stageはfileの場所を表します。
- B: file formatはfileの解釈規則です。
- C: 正解です。
- D: sequenceは数値列を生成します。
## 周辺知識
Stage、file format、pipeは組み合わせますが責務が異なります。
