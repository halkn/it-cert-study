## 問題

Snowflake tableへloadしたdataの最適化、圧縮、columnar形式、micro-partitionを主に管理する層はどれですか。

## 選択肢

- A. Snowflake CLI
- B. Database Storage
- C. Cloud Services
- D. Virtual Warehouse

## 正解

B. Database Storage

## 正解理由

Snowflakeはtable dataを最適化・圧縮されたcolumnar形式でcloud storageへ保存し、物理配置やmicro-partitionなどを自動管理します。

## 各誤答が誤りである理由

- A: Snowflake CLIはSnowflakeを操作するclient toolです。
- B: Snowflakeはtable dataを最適化・圧縮されたcolumnar形式でcloud storageへ保存し、物理配置やmicro-partitionなどを自動管理します。
- C: Cloud Servicesはmetadataやquery最適化などを調整しますが、永続table dataを保持する主層ではありません。
- D: Virtual Warehouseは処理を実行するcomputeです。

## 周辺知識

Apache Iceberg tableなど、external cloud storageを利用するtableもあります。table typeの詳細はObjective 1.5で扱います。
