## 問題

local Git repositoryのPython codeを編集しながら、Snowpark Python stored procedureをauthoring・debugし、同じIDEでSQLも実行したい場合の第一候補はどれですか。

## 選択肢

- A. Snowflake Extension for Visual Studio Code
- B. Snowsightのcost dashboardだけを使う
- C. COPY INTO
- D. Resource monitor

## 正解

A. Snowflake Extension for Visual Studio Code

## 正解理由

公式VS Code拡張はSnowflake接続、SQL実行、object探索に加え、Snowpark Python stored procedureのauthoringとdebugをIDEへ統合します。

## 各誤答が誤りである理由

- A: 正解です。
- B: cost dashboardは利用量監視が目的で、local codeのdebug環境ではありません。
- C: COPY INTOはdata load／unload用SQL commandです。
- D: resource monitorはcredit利用の監視・制御に使うobjectです。

## 周辺知識

local Python interpreter、Snowflake connection、Snowflake側role privilegeは別々に成立させる必要があります。
